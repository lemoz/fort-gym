Keyboard controls or workshop shortcuts?

Three paired repeats from the same starting save, with empty starting memory and the same 120 × 40 screen. Both conditions allow standard keyboard input. The shortcut condition adds selected-workshop job insertion and its instructions. Each attempt has the same 128-decision budget.
