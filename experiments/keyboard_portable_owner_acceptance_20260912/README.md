# Portable public-owner acceptance

This is a new acceptance campaign, not a migrated frozen comparison replicate.
Run two real Astra Medium decisions from the retained native seed using the
public Docker owner, then two more from its own newly settled checkpoint.
The condition, prompt, controls, memory and cumulative usage stay unchanged.

The exact runtime is independently native-load verified at source 7acb4f72b.
The image already exists locally. Start only the existing fg-portable VM, one
game at a time, and stop every owned container and the VM after each window.
No image rebuild, cloud VM, paid API fallback, credit purchase or reset is used.
Fresh subscription admission is required before every inference. Returned
tokens are recorded; monetary charges remain unknown unless reported.

Before continuation, bind its declaration to the actual checkpoint digest,
cursor, campaign identity, original condition and saved usage. Do not retry a
failed inference or repurpose an earlier failed output directory.

portable-runtime-20260912/native-acceptance-v1/owner-acceptance-v1.

published. Four responses do not establish model performance or sustainability.
