to inspect a variable number of native save segments. It rejects gaps, extra

may occur before any response in a later segment; completed earlier segments

The helper also accepted the actual Astra1, Sol1 and Terra1 single-segment
terminal records in a read-only local check. It does not verify native-save
contents, model receipts, memory/usage, game calendars or VM teardown. A full
multi-segment owner and auditor must still bind and verify those evidence
layers before launch. Historical owners and native source remain frozen.

This isolated preparation checkout does not replace the current website,
change its registered results, start a VM or make model calls. Year-Two
