# Matched endurance continuation configurations

These are proposed next windows from the audited decision-64 saves of Astra1,
Sol1, Terra1 and Terra2. The remaining Sol2 and Astra2 continuations must finish
and pass their audits before the six-attempt next-stage input packet is complete.
No decision-64-to-128 gameplay or launch admission is claimed by these files.

Each JSON file is reproduced by `scripts.campaign_matched_endurance_window`,
using the original 32-response public record followed by its own audited
32-to-64 continuation. The public files and both digests are retained in this
branch. The native checkpoint itself and private agent/trace/usage inventories
remain in their existing run artifact locations, not the remote repository.

Follow the original cohort order: Astra1, Sol1, Terra1, Terra2, Sol2, Astra2.
Do not tune prompts or advance selected winners early. Continue the same attempt,
model, medium reasoning, keyboard controls, 120x40 screen, memory and cumulative
allowance. The shared 1280-response / 40000000-token ceilings are unchanged;
the next window owns only 64 additional responses after runtime admission.

See [the endurance-window protocol](../../docs/MATCHED_ENDURANCE_WINDOWS.md)
for execution prerequisites, reproduction and the later comparison stages.
