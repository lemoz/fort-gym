# Selected-workshop controls study v1

Prepared conditions for three paired Astra Medium repetitions. This directory
contains no gameplay results and is not a runtime launch receipt.
See [the study protocol](../../docs/SELECTED_WORKSHOP_CONTROL_STUDY.md) for fixed
attempt identities, ordering, common budgets, measures and required native checks.

`keyboard-condition.json` and `shortcuts-condition.json` differ only in their
identity, versioned action contract and required control instructions. Their
trial files bind the same source snapshot, display, observation, resource
measurement and save policies. Neither condition can reinterpret an old trial.

Source bindings, a new immutable image, verified capacity and teardown ownership
must be retained before any scored run. Continuation requires each attempt's own
saved checkpoint and original model memory/usage, not a reset to this fresh seed.
