# Recorded saved-game continuations

`/public/keyboard-cohort-continuations` exposes an explicit registry of audited
decision-32-to-64 windows. The six declared attempts keep their original order;
unpublished outcomes remain null. The existing initial-result API is unchanged,
and a live observation cannot populate a recorded result.

Every registered file is digest-bound and linked to an immutable remote commit.
The API checks the own parent checkpoint, initial result, model conditions,
window declaration, memory-preservation flags, carried-over usage and saved
time. Each after-action record must reconcile to its cumulative campaign clock
and the final saved metrics. All continuation windows use the declared 32 GiB
storage setting; original first-window differences remain historical evidence.

The page shows new and cumulative ticks/tokens separately, with expandable
decision histories, checkpoint/reload distinctions, clock outcomes, sampled
jobs, teardown results and source links. Missing data stays unknown and refresh
failure preserves previously loaded records. Dollar charges and production rates
remain unreported; neither completed short windows nor accepted keys establish
sustainable production or a model ranking.

This update adds no native-game actions, model calls, private artifact discovery,
runtime changes, dependencies or public deployment. The current preview must be
replaced only after exact-source checks, not hot-edited during observation.
