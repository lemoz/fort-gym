64-to-128 result manifests. It retains the historical decision-64 records and
the first two previously visible endurance results without rewriting them.

All saves record seven living citizens and zero recorded citizen deaths.
None establishes sustainability or one full elapsed year. Equal decision
counts do not mean equal game time or tokens. Two attempts per model using
the same seed are pilot evidence, not a general model ranking. Missing room
measurements and unreported subscription charges remain unknown, not zero.

The new registry entries link exact result and declaration revisions on
GitHub. Its tests cover complete totals, negative outcomes, unavailable
metrics and preserved own-save histories. No HTML, JavaScript, dependency,
database schema, native game, prompt or model configuration changes are
part of this website patch. The existing live observer remains specifically
for 64-to-128 windows and cannot describe a future 128-to-256 run.

Local preview acceptance and public deployment are separate. This source
change does not itself deploy the website or prove fresh gameplay.
