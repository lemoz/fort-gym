# Matched campaign comparison and continuation feed

The recorded comparison exposes all six initial decision-32 windows: two attempts
each for Astra, Sol and Terra. Every result retains its immutable source link,
content digest, all 32 decision boundaries, original storage condition and measured
outcomes. This same-seed pilot does not establish a strong model ranking.

The saved-game feed is separate from the initial-start feed. It displays the
verified starting checkpoint and provisional new responses, tokens and observed
ticks. It adds prior saved usage exactly once. The first continuation request's
feedback belongs to the previous window and is excluded from new elapsed time.
An unknown new-time observation stays unknown even though the saved starting
time is known. Neither a live controller nor its reported teardown verifies a
new save; terminal audits remain the source of saved-result proof.

The API reads a bounded public derivative at
`/public/keyboard-cohort-continuation-active`. Its identities, own checkpoint,
source result, window digest and 32-GiB continuation storage setting are checked
against the immutable six-input packet. It emits no private memory, prompts,
screens, account identifiers or host process paths. Original endpoints remain
available and original result files are unchanged.

The read-only `scripts.campaign_continuation_observe` command attaches to an
already-running owned continuation. It verifies the real checkpoint inventory,
preserved memory and settled usage, the matching launch/operator and the complete
six-input declaration packet. Its process identity includes start time; reused
PIDs end the observation. Read failures do not restart gameplay or assert that
the owner has died. Observations expire after 30 seconds in both API and UI.
The observer calls neither the game nor the model and does not write to original
receipts. It requires explicit local paths for the existing owner, checkpoint,
operator and public derivative directory, not a browser-supplied path.

The native image, model prompt, game controls and campaign budget are not changed
by this website update. Subscription dollar charges remain unreported. The local
preview and GitHub implementation are distinct from public deployment.
