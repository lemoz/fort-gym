# Paired-controls Results panel

The `/results#controls-comparison` section shows all six saved 128-decision
endpoints from the completed Astra Medium v2 study. Rows are grouped by pair,
not rank, and link directly to the original recording and result manifest.
The table is ordinary HTML and remains readable without JavaScript. It reuses
the current Results table styling and a keyboard-focusable horizontal scroller.

`web/static/controls-study-comparison.json` is the byte-identical original summary
from commit `26edd37c0f5946bfb4f0a98d30ae432d8d590e7f`, where the declaration,
six results and read-only reproduction command are bundled. Its SHA-256 is
`84db13cefc663f84c4016d2182ca9a34c974710517dab9640a15ab8919b9ef17`.
Tests bind every visible value and replay link to that report and the retained
native captures. The source and HTTP tests are not browser visual QA.

Both conditions use standard input; one additionally permits selected-workshop
job insertion with its declared instructions. The three pairs share one seed,
empty initial memory, a 120x40 screen and equal decision limits. Game time and
token use differ. Shortcuts request work, not instant completed production.
Unknown dollar charges, stock-versus-production limits, separate endurance data
and the lack of an independent final-128 reload remain explicit in the panel.

This increment leaves all existing recordings, live-feed state, saved outcomes,
three-model reports, historical benchmark fields, runtime code and dependencies
unchanged. Publication is a static-only update on the established host, not a
new Sites project, application deployment, service restart or native run.
