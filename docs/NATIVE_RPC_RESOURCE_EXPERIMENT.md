Opt-in resource snapshots read bounded proc and cgroup files without spawning a
process, reading credentials, changing limits or changing game state. They
retain visible process/thread/zombie counts, scan completeness, and namespaced
v2 memory/PID counters. Missing data stays unknown. PID counters include threads;
`pids.events` can record limit violations, as described in the
[kernel cgroup documentation](https://www.kernel.org/doc/html/latest/admin-guide/cgroup-v2.html).
Snapshots are observations, not automatic root-cause diagnoses.
